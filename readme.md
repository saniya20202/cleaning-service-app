🧹 Cleaning Service Management App
A full-stack web application where users can book cleaning services and admins can manage services and bookings.

Built with:

Frontend: React + Tailwind CSS

Backend: Node.js + Express + MongoDB

*
*
*
🚀 Features
👤 Users
Register and login with JWT authentication

Book a cleaning service (name, address, date/time, service type)

View their own bookings

Edit or cancel bookings

🛠 Admin
View all user bookings

Create and delete services

*
*
*
🧰 Tech Stack

Area	Technology
Frontend	React, Tailwind CSS, Axios, React Router
Backend	Node.js, Express, JWT, Mongoose
Database	MongoDB Atlas


download the zip file from github and extract it.

1️⃣ Setup Backend

✅ Step 1: Open terminal in backend folder
In VS Code terminal: 

    cd backend/backend-cleaning-service

✅ Step 2: Install dependencies
    
    npm install
    
This will install:

express

mongoose

dotenv

cors

bcryptjs

jsonwebtoken

✅ Wait for it to finish (you’ll see node_modules/ appear).

✅ Step 4: Start the backend

Run:this on terminal 
  npm start

✅ If everything is okay, you'll see:
  MongoDB Connected
  Server started on port 5000

*

✅ How to Start Frontend (React)

✅ Step 1: Open terminal in frontend folder
In your terminal:
cd frontend/frontend-cleaning-service

✅ Step 2: Install dependencies
npm install

📦 This installs:

react

react-router-dom

axios

tailwindcss

postcss

Wait for it to finish — you’ll see a node_modules/ folder appear.

✅ Step 3: Start the development server
npm start

✅ This will launch your React app in the browser at:
http://localhost:3000/


✅ Done! Now you have:

Part	Status
Backend	Running on port 5000 ✅
Frontend	Running on port 3000 ✅
Fully connected & working ✅
